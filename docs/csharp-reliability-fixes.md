# C# 可靠性修复（开发版）

本轮修复审查发现的六项问题，伙伴与 AI 自玩继续共用原有工具和执行链路。

- 箱子整理先检查原生堆叠兼容性，再填充最早的兼容槽位；不同原料的果酒不会因 ID、品质相同而被合并。
- 伙伴存档升级为版本 2，在观察摘要之外保存完整原生物品状态，保留原料、价格、品质、附魔、自定义数据与槽位。版本 1 继续通过旧摘要读取；此前已丢失的属性无法恢复，原生数据解码失败时中止恢复，不使用摘要替换物品。
- 采木、清障、浇水、收获、耕地、种植、箱子与出货寻路分帧推进，包括动态重规划、浇水顺序评估及建筑目的地站位选择。暂停、取消与终止清理当前搜索，恢复或角色位置变化后重新规划，世界读取继续在游戏线程执行。
- 原生适配器确认成功后立即记录效果与资源，取消、超时和预算终止均保留真实成果；验证阶段不会重复计数。
- 取消标记只阻止执行，不拦截结果查询；迟到取消返回已缓存的真实终态，不改报为“尚未执行”。
- 工作预算扣除明确暂停的游戏时间，重复暂停不重置已用预算；结果仍报告完整观察时长，接管后不会自动恢复执行。

2026-11-20 验证：Mod 测试 732 项中 729 项通过，3 项未通过分别是缺少 .NET 6 SDK 的独立扩展构建测试，以及在未修改基线同样失败的两项混合掉落物拾取测试。传输测试 61 项中 60 项通过，剩余断线时序测试也在未修改基线复现；关联 Python 提示词测试 8 项通过，生产边界扫描通过。

本轮没有启动真实游戏或使用玩家存档，固定三组伙伴实机回归尚未执行。Windows 本地测试包的构建与完整性验证记录在本次交付说明中，未安装到玩家游戏或发布。
