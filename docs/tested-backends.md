# 模型后端验证范围

桌面接入验证使用隔离存档、测试回执或模拟客户端。真实模型的决策和持续游玩需要另做验收，具体表现也受模型、推理档位和本机配置影响。

| 桌面后端 | 已验证 | 待验证 |
| --- | --- | --- |
| Pi | 本机客户端发现、同一会话恢复、工具调用与取消；用模拟模型验证桌面改派、导航和核对回执。 | 在线模型的长时自动经营与跨日。 |
| DeepSeek（dsh） | 本机客户端可随桌面启动并连接隔离存档。原 Mod 曾验证 `deepseek-flash` 的真实对话。 | 桌面路径下的真实模型持续经营。 |
| Codex | 本机客户端可随桌面启动并连接隔离存档。原 Mod 有九场景决策与实机经营记录。 | 桌面路径下的真实模型持续经营。 |
| MiniMax Code | 模拟客户端验证本机模式及原会话列出、接续、收发、断开和玩家接管。 | 真实账号长回合和三组固定伙伴实机回归。 |

工具与画面实际变化以游戏观察和回执为准。费用按模型服务商或订阅计划计费，桌面估算取决于已有回执和配置单价。[用量说明](desktop-portable.md#进阶设置与用量)

欢迎贡献验证结果。请注明日期、游戏和 SMAPI 版本、模型与推理档位，附去标识化的复现条件、游戏回执和实际结果。[隔离实机回归](repeatable-companion-acceptance.md)
