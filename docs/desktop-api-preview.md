# 星露谷游戏伴侣 · API 绿色候选使用说明

1. 准备 Windows x64、已安装 SMAPI 的《星露谷物语》。将 ZIP 完整解压到可写目录，双击根目录的 **星露谷游戏伴侣.exe**。
2. 在「设置」选择游戏目录和玩法。选择 DeepSeek 或 OpenAI，填写该厂商的 API Key，选择模型，可先点击「测试连接」。
3. 点击「启动游戏」，进入单人存档后在桌面的「今天」发送指令。AI 自玩时先点「交给 AI」，游戏里按 **F9** 接管。关闭桌面窗口时可最小化到 Windows 通知区域。

Node、模型 SDK 和桌面运行库随包提供。桌面配置和按存档关联的伙伴数据分别保存在解压目录的 `data/desktop-settings.json` 与 `data/companion.sqlite`。API Key 由当前 Windows 用户的凭据管理器保存，换目录或电脑后重新填写。模型会收到游戏观察、指令及相关伙伴记忆。

绿色候选已完成模拟模型的连接、原生移动、F9 接管和同存档模型切换。真实厂商 API 和固定农活实机回归列入正式验收。
