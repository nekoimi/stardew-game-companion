## 2026-11-24：桌面状态连接反复断流

根因是 SSE 发送将 `write(false)` 当成连接故障直接销毁响应，工作状态超过写缓冲或连续事件积压时触发。现改为等待 `drain`，历史消息逐条补发，实时事件有序排队；队列限制与停滞超时只释放无法继续读取的订阅。

客户端仅确认完整事件的游标，短暂断流使用独立的本地连接通知，保留游戏绑定、工作视图、选择和草稿；恢复前禁用提交与控制，权威状态确认游戏断开时仍正常清理。

- TypeScript 44 项通过，新增实际 HTTP 缓冲排空、256 条超过 8 MiB 的历史补发、慢订阅读取、清理和正式服务大工作状态推送回归。游戏端使用本机假 WebSocket，不启动游戏。
- WPF 本地协议与展示回归通过：半帧断开后从上个完整游标恢复、不重复投递半帧、保留草稿与视图、恢复按钮和区分实际游戏断开。
- 修复包位于 `artifacts/desktop-stream-fix-1124/`，与玩家运行目录隔离。未执行本次实机或真实模型验收，未启动、重启或关闭玩家游戏。
