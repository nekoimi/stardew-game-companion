# 游玩模式与控制权

## 两种模式

| 模式 | 谁控制什么 |
| --- | --- |
| 伙伴模式 | 你操作玩家，AI 操作独立伙伴。伙伴拥有自己的背包、工具与体力。 |
| AI 自己玩（首次启动默认） | 点击「交给 AI」后，AI 操作单人角色。 |

在「设置 → 游戏启动」选择模式，修改后需要重启游戏。

寻路和农事移动支持直走和斜走，通畅的路段连续通过。经过门口、狭窄通道和工具交互点时，游戏会先对准站位。

## 暂停、改派和接管

- **暂停 / 继续**：控制当前工作是否继续推进。
- **取消当前工作**：停止不再需要的工作。
- **打断并执行**：发送新的要求，等旧动作结算后再按新要求安排。
- **F9**：在游戏窗口立即接管，AI 不会自动抢回控制权。

动作结果以原生回执和游戏观察为准。出现「待核对」时，先点击「核对旧动作」，确认旧动作终态再继续。

## 长期目标与休息

可以明确交代持续目标，例如“这批种子种好后，接下来继续照料这片菜地”。伙伴结合当天观察和资源安排下一步。长期偏好本身不会开启工作。

照料作物时，AI 可按需补水并接着浇。收获、拾取、入箱和出货也可以分批进行，执行中可以追加要求。要留种或保留材料时，可以在指令里写明数量。

持续目标可等待次日、约定游戏时间或农田作物变化后接续。当天暂无可做的农活时，等待不会取消目标；移动和游戏时钟变化本身不会反复触发农田复查。

两种模式都使用「设置 → 存档偏好」的就寝时间，并提前留出返程时间。AI 操作主角时会回床保存过夜，次日根据新观察继续；伙伴模式由玩家决定何时结束当天。

伙伴模式下，头顶名字来自「存档偏好」，休息时隐藏。当前没有 GUI 外观编辑器，第三方外观 Mod 对独立伙伴的兼容性需要另行验证。
