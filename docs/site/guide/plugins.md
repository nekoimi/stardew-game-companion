# 插件中心

插件用于扩展伴侣功能。桌面管理插件进程和通用通信，具体业务规则与设置由插件负责。

## 安装与启用

1. 在「插件中心」点击「安装本地插件」，选择插件 ZIP。
2. 核对来源和发布者后确认安装。
3. 启用插件，有设置页时点击「打开插件设置」。设置页在浏览器中打开。
4. 需要自动启动时，打开「随伴侣程序自动启动」开关。

也可以在「在线目录」填写 HTTPS 地址，发现并安装兼容版本。宿主会核对签名与 ZIP 哈希。

## 运行与停止

插件可以先于游戏运行。读档后可订阅公开状态、接收伙伴回复、提交独立指令并查询结果。「今天」会标明指令来源，玩家仍可暂停、改派或用 F9 接管。

最小化到托盘后，插件继续运行；退出伴侣时停止由它启动的插件。「停止插件」会中止其活动回合，插件显示「需重启」时可从详情页重启。

## 更新、回退和卸载

在线目录支持更新，详情页可回退到更新前的版本和数据。卸载确认框默认勾选「保留插件的数据与设置」。日志可从插件详情页打开。

这里的桌面插件与游戏中的 SMAPI Mod 是不同的扩展入口。开发插件请阅读[接入概览](/plugins/)。
