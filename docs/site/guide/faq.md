# 常见问题与日志

## 需要安装 Node 或模型客户端吗？

不需要。绿色包提供 Node、Agent 与桌面运行库。你需要准备游戏、SMAPI 和可用的模型 API Key。

## 模型连接失败怎么办？

在「设置 → 模型连接」运行「测试连接」，按提示核对 Key、模型 ID、协议和 Base URL。模型必须支持工具调用，接口不支持流式时关闭流式输出。

托管中的模型请求遇到临时限流或断线时，会进入「等待重试」。看到「模型调用失败」时，可按界面说明处理后重新发送要求。

## 游戏时间暂停是否代表卡死？

模型思考或保护暂停可能暂停游戏时间，桌面会显示原因。如果整个画面、菜单和输入都停顿，打开日志查找对应时段的 `slow_game_tick` 事件。

动作显示「待核对」时，先核对旧动作，避免把缺失回执误当作没有执行。

## 桌面提示连接中断，但游戏仍在运行？

「桌面连接中断 · 正在自动重连」表示本机状态推送暂时中断，不能据此判断游戏退出；桌面保留当前进展、所选目标和输入草稿，恢复后按最新状态更新。此时不要重复提交任务，需要停止游戏动作时可在游戏中按 F9 接管。若提示「伙伴服务已退出」，使用「重连伙伴服务」后按提示核对旧动作。

## 日志在哪里？

点击「诊断 → 打开日志目录」。默认位于当前数据位置的 `data/logs`，每行一条 JSON。SMAPI 继续管理自己的游戏日志。

单文件最多 10 MiB，启动与写入期间自动清理 14 天前日志，总量超过 100 MiB 时优先清理可删除的最旧文件。可用环境变量 `STARDEW_COMPANION_LOG_DIR` 设置绝对路径。

产品日志不写入聊天正文、模型原始请求或 API Key。分享前仍应检查并移除私人路径和存档信息。

## 如何升级与回退？

在「设置 → 关于与更新」可通过版本目录检查并下载更新，也可以选择本地 ZIP。访问默认地址不便时，可以填写可信镜像的 HTTPS 版本目录地址。保存并退出游戏后再安装，新版自检失败会自动恢复旧程序。[更新与回退](/reference/desktop-guide#更新与回退)

## 如何报告问题？

到 [GitHub Issues](https://github.com/nekoimi/stardew-game-companion/issues) 提供版本、游玩模式、复现步骤、预期行为和实际结果，必要时附上经过检查的相关日志片段。
