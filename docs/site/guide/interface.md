# 桌面页面说明

多数页面按当前存档展示数据，需要先进入单人存档。

| 页面 | 作用 | 主要操作 |
| --- | --- | --- |
| 今天 | 当前对话、思考／寻路／执行状态、最近进展、控制权与待确认选项。 | 发送要求、暂停、继续、取消、打断并执行；Ctrl+Enter 发送。最近进展可重新查看游戏或核对旧动作，不自动重做。 |
| 农场工作 | 按目标、请求和日期整理阶段进展与实际数量，显示仍需复查的工作。 | 完整过程默认折叠；旧版未关联的回执单独保留，撤回不再需要的目标。 |
| 计划 | AI 提出的阶段性建议和目标日期。 | 采纳或暂缓。当前采纳只保存计划状态，不会直接启动执行。 |
| 对话历史 | 当前存档保存的交流记录。 | 读取最新、查看更早记录。 |
| 伙伴消息 | 作物照料、回家时间、工作结果等提醒，以及已关闭的待确认事项。 | 标为已读，恢复已关闭事项后回「今天」回复。 |
| 手记 | 长期偏好与约定。 | 新增、修改或删除；系统共同经历不能手动改写。 |
| 插件中心 | 安装、配置和管理扩展。 | 管理启停、自动启动、在线目录与回退。 |
| 设置 | 游戏启动、模型连接、当前存档偏好。 | 配置游戏、模型、名字、性格、就寝时间和主动帮忙。 |
| 用量 | 全局、当前存档和最近任务的模型用量。 | 刷新查看请求次数、重试、输入和输出 Token 及缓存读取。服务商未提供的用量显示「未记录」。 |
| 诊断 | 日志目录与入口。 | 打开文件日志目录。 |

## 目标、记录和记忆的区别

例如你说“把作物浇完，保留幼树”：

- 工作是否完成，在「农场工作」查看。
- 当时说过什么，在「对话历史」查找。
- 希望今后一直遵守的要求，写入「手记」，例如“保留幼树”。

初次测试时，先使用「今天」「农场工作」和「手记」即可。计划目前是基础实现，不应视为完整自动排程。

「最近进展」显示已确认的历史回执，跨日或超过两分钟会提示重新观察。物品数量来自收集、转移或背包变化；没有数量证据时不显示数量，阶段进展不代表整个目标已经完成。
