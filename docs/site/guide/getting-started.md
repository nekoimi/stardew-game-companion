# 安装与首次启动

星露谷游戏伴侣是一款 Windows 桌面程序。你可以让独立伙伴帮忙，也可以把单人角色交给 AI 操作。

## 准备环境

- Windows x64。
- 已安装《星露谷物语》和 [SMAPI](https://smapi.io/)。
- 可用的模型 API Key，模型调用费用由所选服务商收取。

项目处于 0.x 开发阶段，建议先备份存档。Node、Agent 和桌面运行库随绿色包提供，无需安装模型客户端。

## 下载与启动

1. 从 [GitHub Releases](https://github.com/nekoimi/stardew-game-companion/releases) 下载 `StardewGameCompanion-<版本>-windows-x64.zip`，开发版位于预发布条目。
2. 可用同名 `.sha256` 核对下载，完整解压到可写目录。
3. 双击根目录的 **星露谷游戏伴侣.exe**，程序默认进入「今天」。
4. 在「设置 → 游戏启动」选择包含 `StardewModdingAPI.exe` 的目录和游玩方式。
5. 在「设置 → 模型连接」配置模型，点击「测试连接」并保存。
6. 点击「启动游戏」，在游戏窗口进入单人存档，再回到「今天」发送指令。

![启动后的今天页面，尚未连接游戏](/desktop-home.png)

## 第一次交代工作

先尝试一个明确的小目标，例如：

> 把农舍前的作物浇完。

「AI 自己玩」模式需要先点击「交给 AI」。在「农场工作」查看目标、进度和回执，在游戏窗口按 **F9** 可立即接管。

## 退出和更新

关闭窗口时可选择最小化到托盘，双击通知区域图标恢复。退出伴侣会停止 Agent，游戏仍需由你保存并退出。

在「设置 → 关于与更新」可检查正式版，也可勾选「检查预览版」。保存并退出游戏后再安装，更新会保留设置和伙伴资料。[更新及数据迁移](/reference/desktop-guide#更新与回退)
