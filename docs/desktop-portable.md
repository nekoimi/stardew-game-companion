# 星露谷游戏伴侣使用指南

## 启动

1. 准备 Windows x64、《星露谷物语》及已安装的 SMAPI。将绿色 ZIP 完整解压到可写目录，双击根目录的 **星露谷游戏伴侣.exe**。
2. 在「设置」选中包含 StardewModdingAPI.exe 的游戏目录和游玩方式。配置厂商、模型和 API Key，点击「测试连接」。
3. 点击「启动游戏」，加载单人存档。在「今天」发送自然语言指令。

Node、模型 SDK 和桌面运行库随包提供。启动器加载绿色包的独立 Mod 目录。关闭窗口时可最小化到通知区域，双击图标恢复。退出伴侣会停止 Agent，游戏由玩家保存并退出。

## 模型配置

- **DeepSeek 和 OpenAI 官方**。选择服务商、模型，填写该厂商的 API Key。支持的推理档位按模型显示。
- **OpenAI 兼容（Responses）**。填写 HTTPS Base URL、网关模型 ID 和该网关的 Key。Base URL 保留接口前缀（如 /v1），填写到 /responses 之前。换地址后需填写该端点的 Key。
- 「测试连接」核对流式工具调用和回执。进入存档后可在空闲时点击「应用模型」，继续使用同一角色、手记、对话和工作目标。

桌面设置在 data/desktop-settings.json，伙伴资料和用量按存档存在 data/companion.sqlite。API Key 由当前 Windows 用户的凭据管理器保存，换目录或电脑后重新填写。模型会收到指令及相关游戏观察、工具结果与手记。

## 和伙伴一起玩

「AI 自己玩（单人）」为首启默认。点「交给 AI」后允许 AI 操作玩家角色，按 **F9** 随时接管。伙伴模式下，AI 操作有独立背包、工具和体力的伙伴。更改游玩方式在游戏重启后生效。

| 桌面位置 | 可以做什么 |
| --- | --- |
| 今天 | 查看对话、进度、原生回执和待确认选项，Ctrl+Enter 发送。「打断并执行」会等上一项动作结算。 |
| 农场工作 | 查看当前目标、等待原因及近期执行记录，撤回不再需要的目标。 |
| 对话历史 | 回看当前存档的对话。 |
| 计划与伙伴消息 | 查看计划、处理提醒和待确认事项。 |
| 设置与手记 | 设置角色名字、相处方向与主动帮忙偏好，编辑记忆及约定。 |
| 用量 | 查看全局和当前存档的用量。缺失项显示「未记录」。 |

收获与清障后的行动以原生回执、附近掉落物和背包观察为准。若桌面显示「待核对」，点击「核对旧动作」。同一游戏中须确认旧动作终态再继续。重新读档会建立新的游戏会话。

路线规划超时会返回动作失败。伙伴可根据当前地图重查落点，继续尝试附近可站立的格子。

## 更新与回退

1. 保存并退出游戏，确认退出旧伴侣。下载 ZIP 并核对随附 SHA256，将新版解压到独立目录。
2. 在新版重新设置模型。如果升级的是同一 TypeScript 版数据格式，可在两个桌面都关闭时复制 data/desktop-settings.json 和 data/companion.sqlite。
3. 需要回退时先保存退出新版，再打开独立旧目录的 EXE，继续使用旧目录内的设置和伙伴资料。游戏存档由《星露谷物语》保存。

## 排查

- 模型连接失败时，在「设置」运行「测试连接」，按提示核对 Key、模型和端点权限。
- 时钟因模型思考或保护暂停时，桌面会标明原因。画面与输入同时停顿时，可在「诊断」查看对应时段的游戏帧耗时。
- DeepSeek 官方与第三方 Responses 已通过真实固定场景和同存档切换验证。验收细节见源码仓库中的改造记录。
