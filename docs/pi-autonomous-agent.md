# 持续自主 Agent（首版）

在桌面「设置」选择 Pi 后端，即可把宽泛方向交给伙伴持续推进；日常步骤由模型结合现场决定，程序保留原始委托、进度和等待条件。伙伴与 AI 自玩共用这套能力，自行睡觉和跨天请使用单人 AI 自玩模式。

## 配置与使用

安装 Node.js ≥22.19.0 并安装、登录 [Pi](https://github.com/earendil-works/pi)（`npm install -g @earendil-works/pi-coding-agent`），要求具备 MCP、RPC、`get_state`、`agent_settled` 和 `--approve` 接口（按 1.5.2 协议接入）；旧版不支持时需升级。桌面上模型留空时沿用 Pi 当前模型。调试旧的游戏内启动路径时，可在运行目录的 `config/chat-backend.json` 写入：

```json
{"backend":"pi","model":""}
```

源码环境可启动 `uv run --project runtime python -m stardew_ai_runtime.chat_bridge --run-dir "实际 Mod 目录" --backend pi`；自定义可执行入口用 `--pi-cmd`。游戏仍需加载匹配的 Mod 与运行时；更改设置后重启伙伴服务，游戏模式更改重启游戏生效。

通过 fnm 安装 Node/Pi 时，游戏启动器支持查找 fnm 的默认别名及相邻 Node；请在 `fnm default` 对应的版本下安装 Pi。只在某个终端临时切换的 Node 环境安装、默认版本未安装 Pi 时，启动器不会猜测其他版本；PATH 中明确配置的 Pi 优先。

在桌面「指令」中输入“农场交给你持续经营，先发展种植，幼树留着”。伙伴保存它对目标的理解后自行行动；有明确时限或保留要求请一并说明，普通闲聊与进度询问不会开启持续委托。

工作中可以追加“先别卖东西”或“今天先把照料做完”；桌面可查看进度、暂停、继续或取消，单人自玩按 F9 接管，明确交还后才恢复自动行动。持续经营方向不会因一天工作完成而结束，要结束时取消该安排。

## 接续与恢复

游戏模型仍使用八个工具入口。`manage_arrangements.change.delegate_goal` 将当前玩家原话绑定为持续目标，`set_goal_continuation` 保存下一步或 `wait` 条件；具体动作立即执行，不新增持久动作队列。

等待支持原有 calendar、gameTime、resource、inventory、crop、machineReady 条件；全目标等待期间停止重复推理，条件满足后再决策。尚需做的其他工作与未来提醒分别处理；玩家模式仍须调用原生睡眠，临近夜间会重新提供决策机会。

无动作的连续回合有上限，真实位置、物品和资源变化可重新提供决策机会；等待玩家回答时暂停该目标。Pi 限制连续无响应间隔，正常有事件进展的回合没有总时长截断。

Pi 会话文件保存在运行目录 `data/pi/sessions`，每轮重新打开同一会话和所属 RPC 进程，以刷新工具权限并释放游戏连接。缺失或返回不同会话时报告错误，不创建替代会话；读档或会话压缩后重建游戏上下文，退出只取消并清理所属进程，不关闭玩家原客户端。本版维护游戏专属 Pi 会话，不接管已打开的 Pi 终端对话；首次使用沿用 Pi 保存的默认模型，恢复时沿用游戏原会话。

## 首版边界与验证

首版提供后端、持续委托、条件等待及控制接线；不包含任意攻略链接导入，参考知识继续通过已有 `consult` 指导与 wiki 提供。游戏动作仍受当前角色模式、工具、材料和原生交互支持范围限制；首次创建持续委托需在伙伴可执行时提交，暂停或接管中请先恢复再重新提交。

离线回归覆盖真实假 RPC 子进程、消息送达、会话恢复、取消、超时、跨日唤醒与等待边界；它不证明真实模型可稳定连续经营。真实 Pi 模型的隔离存档跨日游玩、画面和三组伙伴实机回归需单独执行，并如实记录结果。
